# Gestión de Usuarios

Sistema de autenticación y gestión de usuarios con Supabase.

## Características

- ✨ Autenticación segura
- 👥 Gestión de usuarios
- 🔐 Contraseñas encriptadas
- 📱 Interfaz responsiva
- 🎨 Diseño moderno

## Páginas

- [Inicio](index.html) - Página de bienvenida
- [Login](login.html) - Iniciar sesión
- [Registro](register.html) - Crear cuenta
- [Dashboard](dashboard.html) - Panel de usuario

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Supabase
- Jekyll

## Desarrollo

Para ejecutar localmente:

```bash
bundle install
bundle exec jekyll serve
```

Luego accede a `http://localhost:4000`
