# 🔐 Password Recovery & Change Feature Documentation

## Overview

This document outlines the complete password recovery and change functionality implemented in the L2H Community application using Supabase Authentication.

## Features Implemented

### 1. Forgot Password Flow (`forgot-password.html` + `forgot-password.js`)

**Purpose**: Users can request a password reset via email

**User Journey**:
1. User navigates to forgot-password page
2. Enters their email address
3. Clicks "Send link" / "Enviar enlace"
4. Supabase sends a password reset email with a secure link
5. User sees confirmation message: "Check your inbox and click the link to reset your password"
6. Email link is valid for 24 hours

**Technical Details**:
- Uses `supabaseClient.auth.resetPasswordForEmail(email, {redirectTo: ...})`
- Email validation (format checking)
- User existence verification
- Rate limiting handled by Supabase
- Graceful error handling with user-friendly messages

**Supported Languages**: 🇪🇸 Spanish, 🇬🇧 English, 🇫🇷 French, 🇩🇪 German

---

### 2. Reset Password Flow (`reset-password.html` + `reset-password.js`)

**Purpose**: Complete password reset using token from email link

**User Journey**:
1. User clicks link in email (contains access token)
2. Redirects to reset-password.html with token in URL
3. Page validates token automatically
4. User enters new password with strength requirements
5. Real-time password strength meter shows feedback:
   - 🔴 Weak (1-2 requirements met)
   - 🟡 Medium (3 requirements met)
   - 🟢 Strong (all 4 requirements met)
6. Live requirement checkers show:
   - ✓ Minimum 8 characters
   - ✓ One uppercase letter
   - ✓ One lowercase letter
   - ✓ One number
7. User confirms password
8. System validates both fields match
9. Password updated via `supabaseClient.auth.updateUser({password: newPassword})`
10. Success message displayed
11. Auto-redirect to login after 3 seconds

**Security Features**:
- Token validation on page load
- 24-hour token expiration (Supabase default)
- Server-side password hashing (bcrypt)
- Requires 4 security criteria
- Mismatch detection
- Session protection

**Supported Languages**: 🇪🇸 Spanish, 🇬🇧 English, 🇫🇷 French, 🇩🇪 German

---

### 3. Change Password Flow (`change-password.html` + `change-password.js`)

**Purpose**: Authenticated users can change their password at any time

**User Journey**:
1. User (must be logged in) navigates to change-password.html
2. Page auto-verifies authentication (redirects to login if not authenticated)
3. User enters new password
4. **Real-time validation** as they type:
   - Password strength bar updates
   - 4 requirement icons show completion status
   - Clear visual feedback (checkmarks turn green when met)
5. User confirms password
6. Clicks "Change Password" / "Cambiar Contraseña"
7. System validates both match and meet requirements
8. Updates password via `supabaseClient.auth.updateUser({password: newPassword})`
9. Success confirmation displayed
10. Optional: redirect to dashboard or remain on page

**Security Features**:
- Requires active authentication session
- 4-requirement minimum strength check
- Mismatch detection before submission
- Real-time visual feedback prevents errors
- Error recovery (button re-enables on failure)

**Supported Languages**: 🇪🇸 Spanish, 🇬🇧 English, 🇫🇷 French, 🇩🇪 German

## Backend Integration

### Supabase Auth Methods Used

```javascript
// Request password reset email
await supabaseClient.auth.resetPasswordForEmail(email, {
    redirectTo: 'https://yourdomain.com/reset-password.html'
});

// Update password with token
await supabaseClient.auth.updateUser(
    { password: newPassword },
    { accessToken: token }
);

// Update password for authenticated user
await supabaseClient.auth.updateUser({
    password: newPassword
});
```

### Email Flow

1. **Password Reset Email** (Auto-generated by Supabase):
   - Contains secure link with 24-hour expiration
   - Link includes access token in URL fragment
   - Redirects to reset-password.html
   - User clicks link from ANY email client

2. **Email Configuration** (in Supabase Dashboard):
   - Go to: Authentication → Email Templates
   - Customize "Reset Password" template with branding
   - Ensure "Reset Password Link" button is configured

✅ **Authentication**
- Tokens expire after 24 hours
- Email validation before processing
- Session state verification for change-password

✅ **Password Requirements**
- Minimum 8 characters
- Mixed case (upper + lower)
- At least one number
- Enforced on both frontend and Supabase

✅ **Data Protection**
- HTTPS required for production
- CORS configured in Supabase
- No passwords stored in localStorage
- Secure token handling in URL fragments

✅ **User Experience**
- Clear error messages in 4 languages
- Rate limiting by Supabase
- Real-time strength feedback
- Visual requirement indicators

## Support & Troubleshooting

### Common Issues

**Issue**: Email not received
- Solution: Check spam folder, verify email in Supabase console

**Issue**: Reset link shows invalid token error
- Solution: Links expire after 24 hours, request new one

**Issue**: Password requirements not showing
- Solution: Clear browser cache, check JavaScript console for errors

**Issue**: Page redirects to login unexpectedly
- Solution: Session may have expired, login again

### Debug Mode

Enable debug logging:
```javascript
// In browser console
localStorage.setItem('l2h-debug', 'true');
// Reload page
```
